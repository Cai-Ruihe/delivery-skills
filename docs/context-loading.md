Every actual additional trigger adds its reference. Simple work becoming complex must load the necessary rule rather than preserve a small count. Reuse only unchanged instructions and verified state; compaction or changed authorization may require a targeted refresh. Warm reuse means no additional reread, not zero total context. Independent agents each incur their own exposure; do not assume shared cache.

When formal checkpoint conditions first need recovery or change, add reflection: 395 words. An architecture investigation does not load that reference merely because the Architect role was selected. Applicable user-required cadence still governs the work, even when unchanged rules are reused.

Fifteen runtime files total 4,626 words; entries are 166–219 words, references 251–448 words. The raw navigation graph has six simple cycles, each using the recovery-to-execution-loop return link. These are conditional links to the single relevant rule body, not instructions to traverse the graph. Core's eight-file reachable closure describes package completeness, not default eight-file reading.

Compared with the preceding release, the small-task path falls from 241 to 219 words; the ordinary PM path grows from 686 to 798, and the complex architecture path from 1,851 to 2,022. Necessary guidance increased those cold paths. No overall text reduction, token saving, shared cache or delivery speedup is claimed. Actual host exposure and model behavior remain unmeasured.
