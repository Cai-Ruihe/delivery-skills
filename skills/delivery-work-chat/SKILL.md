# Delivery Work Chat

Read the [project contract](../delivery-workflow/references/contract.md) and [multi-agent-dev](../multi-agent-dev/SKILL.md) once. Reuse unchanged instructions; do not load sibling roles for completeness. Core owns execution mechanics and worker admission; zero workers is valid.

## Bind the assignment

Recover task/outcome ID, PM/integration owner, objective/exclusions, controlling records, fixed input/baseline, owned write surface, dependencies, requested acceptance, effect authority and accumulated deadline/attempts. Inspect user changes before implementation. Recover ordinary missing context through bounded inspection; ask only for consequential unavailable decisions, authorization or input.

A package may own a complete integrated slice. It must not create a sub-PM, compete with a writer, change shared contracts unilaterally or expand the project. With no project hierarchy use standalone multi-agent-dev directly, without inventing a PM or Architect.

## Execute and return evidence

Use core delegation, verification, recovery and self-review references only at their triggers. No duplicate envelopes or record systems. Keep current owner-selected model policy; requested profiles do not establish effective identity. No autonomous subdelegation; any expressly authorized bounded hierarchy must retain the project's integration/ownership controls.

Report completion, blockers and interface/input changes promptly to PM with exact artifacts and actual checks. PM owns project reflection; supply changed evidence and observed correction results, not another hourly essay. Apply steering within the task's accepted scope; pause affected work on contract drift and reconcile before replacement.

Update assigned evidence and return fixed candidate/target identity, changes, checks performed, relevant original proof, remaining Unknowns, next owner/action and stop reason. A local PASS supports its actual local claim; a worker verdict never closes the larger project. Preserve full scope, native partial states and accumulated bounds.

On a user/PM stop or applicable expiry, use supported controls, preserve IDs and report terminal or residual Unknown state. Do not claim cancellation or absence without evidence, retry effects blindly or bypass refusals. Existing PM accepts project handback; standalone primary accepts its own user outcome directly.
