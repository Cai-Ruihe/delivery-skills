# Bounded research that returns to execution

Read when complex uncertainty, a critical unclear assumption or recurrence needs external references. Ordinary known bugs use a targeted check, not a research stage or new approval/ledger.

State the decision, existing evidence, what could change it, bounded search/check scope within current limits, and return condition. Prefer official documentation and comparable inspected implementations/tests; use industry/academic evidence when it bears on the question. Check versions, applicability, counterevidence and failure modes. A plausible precedent is not proof it fits.

Independent reference/counterevidence tracks may be delegated when admitted under [delegation](delegation.md). Supply minimal context, isolate writes and retain integration ownership. Public queries use generic technical terms, never private text, charter, code, identity or business data. Research grants no new access/effects; uncertainty in authority uses [recovery](recovery.md).

Return applicable sources and strength, alternatives/cost, minimal discriminating experiment and next action. Stop collecting when evidence selects an action, clearly exposes a knowledge gap, no new query can discriminate, or current bounds require stopping. A link collection alone is not progress. Actual proof experiments use [verification](verification.md) when their seam warrants it; research never substitutes for integration/acceptance.

Consequential architecture trade-offs go to independent Architect/technical judgment; PM implements adopted or authorized binding decisions and verifies. Genuine requirements/design interviews use installed grill-with-research: applicable foundation/pivot and prior-decision search before questions. Reuse current foundations; technical reference checks do not pretend to complete the full grilling protocol. Material changes in users/trust/deployment/regulation/foundational architecture require pivot evidence and authority review before dependent decisions. Do not force every small issue through three-track research.
