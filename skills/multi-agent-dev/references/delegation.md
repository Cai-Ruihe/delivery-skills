# Useful delegation, contact and independent review

Read for dispatch/coordination, contact, fixed-result handback or review organization. Reviewers load their role and relevant fixed inputs, not the organizer's whole context.

Delegate implementation only with a usable interface, identified consumer, isolated writes and integration capacity. Bounded research/diagnosis may first establish the interface or challenge the route. Keep coupled unknowns with one owner; consolidate when coordination exceeds progress. Zero workers is valid; start with at most three within host capacity, not a quota. No automatic hierarchy/chat creation/subdelegation; authorized hierarchies retain these controls.

Use supported tools and owner-selected profiles. Effective identity/profile needs host evidence, not labels. Missing capability/profile is a disclosed gap, never silent substitution. Roles share the same host/worker budget. Give relevant outcome/exclusions, decisions, fixed baseline, owned surface, dependencies, required evidence, allowed effects and accumulated limits. One writer per mutable surface, one serialized controller per external target; preserve user changes.

The integrator consumes fixed artifacts/checks, contract changes and gaps at supported event/call boundaries and checkpoints. Workers may exchange stable evidence, not change shared contracts or close the parent request. Reconcile late/duplicate/reordered messages by task/result version and existing IDs/disposition; stale events cannot replace current decisions or revive expired grants.

For contact verify recipient, decision authority and authorized route. Plan realistic decision opportunities from known availability/agreement, not assumed overnight response. Disclose execution gaps: consent is not readiness. An unverified delivery is a communication gap, not user waiting; reply wall time is not net project delay. Consent/current timing remain separate under [recovery](recovery.md). Unknown sends freeze conflicting continuation, never automatic resend.

Draft, transport, ACK, disposition, execution and acceptance are combinable evidence, not gates. Exact-version disposition or correct-candidate execution can prove receipt without formal ACK repair/repeated dispatch. Reliably save fixed results/evidence in native records; workers may then exit while the confirmed runtime owner retains undisposed obligations. Unproved storage/ownership is a disclosed gap, not indefinite worker waiting or assumed transfer. Safety stopping never waits for ACK.

Reviewers must be non-authors. Supply original intent/constraints/raw inputs before author/peer verdicts where practical; use independent methods and falsifiable findings. Fresh context/model alone is insufficient. Review grants no effects. Bind findings to actual final artifacts; later changes invalidate affected conclusions. Preserve unavailable independence and unperformed acceptance as open; a polished handback is not integration.
