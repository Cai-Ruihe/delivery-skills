# Public delivery references

Maintenance only. These public sources provide context for general operating choices; they do not establish model rankings or permission for external effects.

- [DORA small batches](https://dora.dev/capabilities/working-in-small-batches/) supports feedback through small complete increments.
- [Google SRE release engineering](https://sre.google/sre-book/release-engineering/) discusses repeatable release practices.
- [AWS architectural decision record process](https://docs.aws.amazon.com/prescriptive-guidance/latest/architectural-decision-records/adr-process.html) describes significant-decision review and records.

The operating inference is to keep feedback paths short, bind evidence to actual candidates and retain consequential decisions in existing records. These sources do not validate a particular worker count, failure threshold, model preset or reflection interval. Recheck current documentation when applying specific APIs or procedures. No external manual or implementation is bundled.
