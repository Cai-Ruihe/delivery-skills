# Security policy

The current public snapshot is supported. Report the affected commit, relevant boundary, safe reproduction and observed versus expected behavior.

Use GitHub private vulnerability reporting if available. Otherwise request a private contact channel in a public issue without including credentials, private repository content, prompts, personal data or sensitive exploit details.

Relevant issues include prompt injection, private-context disclosure, unauthorized delegation or effects, competing writers, unsafe retries, ambiguous worker lifecycle, spoofed identity and unsupported acceptance claims.

The skill does not make tools or external services trustworthy. Host controls, sandboxing, permissions and human authorization remain authoritative. Reviews and automated scans cannot guarantee detection of all sensitive information.
